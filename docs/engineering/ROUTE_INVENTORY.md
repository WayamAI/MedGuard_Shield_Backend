**Count: 65 route handlers under `/api` + 2 public health probes = 67 total HTTP endpoints.** The root docs' claim of "87 endpoints" is overstated by ~20; corrected in `GAP_AUDIT.md`.

**RBAC design note** (from `src/lib/permissions.ts`): ADMIN holds every permission; VIEWER holds only the `:read` set; ANALYST holds reads plus a named allow-list (`asset:assess`, `vendor:assess`, `threat:*` except none excluded, `remediation:*`, `access:review`, `control:assess` — field-scoped). This matches ground-rule-10's "Analyst may assess a control but not reconfigure it" exactly, enforced in `controls.ts`'s `canPatchControl`.

**Audit coverage**: every one of the 47 mutating handlers (`POST`/`PATCH`/`PUT`/`DELETE`) has a matching `recordAudit`/`recordAuthEventSafe` call in its handler or the service it calls — confirmed by a mutation-count vs. audit-call-count diff per file, all equal (auth.ts and import.ts show *more* audit calls than mutations because a single import run or login attempt can emit multiple events, e.g. one per imported row's audit trail plus one for the import itself).
